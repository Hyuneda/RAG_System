
📑 RAG System: Hyundai Vehicle Manual Chatbot
현대자동차(MX5) 차량 사용자 매뉴얼 PDF를 기반으로 한 고성능 RAG(Retrieval-Augmented Generation) 시스템입니다. 단순한 텍스트 검색을 넘어, LLM 에이전트가 문맥을 파악하여 정보를 나누는 Agentic Chunking 기술을 적용하여 답변의 정확도를 극대화했습니다.

🚀 핵심 기술 (Core Tech Stack)

LLM 에이전트: AWS Bedrock (Claude 3.5 Sonnet) 



Vector DB: Amazon OpenSearch 


프레임워크: LangChain 


임베딩 모델: Amazon Titan Embedding
